# Post-Quantum Confidential Computing in Permissioned Blockchains

This repository contains all the contents for the thesis project "Post-Quantum Confidential Computing in Permissioned Blockchains".


## Installment

After cloning this repository, you can run the `./intialize_all.sh` command to create the Fabric Private Chaincode Development Environment. Here you can Execute the `./run_deploy.sh` script to deploy the chaincode and create the network. 
Be sure Docker Desktop is open!

## Running Application
The server can be started by executing `./start_server.sh` and  the application can be opened with `./run_client.sh`
